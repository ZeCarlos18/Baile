# 🎮 Guia de Uso

Este documento explica como utilizar o sistema após a instalação.

## 🏠 Criar Sala

1. Acesse a aplicação no navegador.
2. Clique em "Criar Sala".
3. Um código único será gerado automaticamente.
4. Compartilhe esse código com outros usuários.

## 🚪 Entrar em Sala

Para entrar em uma sala existente,use o link que foi compartilhado com você

## 🔍 Buscar Música

Digite o nome da música no campo de busca.

O sistema realiza requisições para:
https://www.googleapis.com/youtube/v3/search


Os resultados exibidos podem ser adicionados à fila.


## ➕ Adicionar Música à Fila

Ao clicar no botão adicionar ao lado do resultado,a musica escolhida entra em uma fila 

## Escolha da musica

A primeira música a ser adicionada é a que será reproduzida por primeiro,a escolha dá proxima musica a ser tocada é feita por um sistema de cartas

Funcionamento

O sistema gera automaticamente uma quantidade de cartas igual ao número de músicas na fila.
Cada carta representa uma música específica.
O usuário escolhe uma carta.
A música correspondente é reproduzida para todos os usuários da sala.
A fila é atualizada automaticamente após a escolha.
